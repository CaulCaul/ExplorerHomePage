# Explorer Home Page

一个 **Edge 浏览器主页扩展**。

页面本身完全本地加载、零必要网络请求——断网、网络差也能秒开主页；
联网后再按需提供搜索联想、网站图标等增强能力。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 📶 双网络角标 | 右下角单气泡双行：圆点颜色 + 国内/国外 + 延迟（ms），点击对应行立即复查；国外通道以 **Google 主站**可达性为准 |
| 🔍 双引擎搜索 | 必应 / Google 图标式切换（内嵌搜索框左侧，圆角滑块指示当前引擎，记忆选择）；输入时给出候选：本地历史（带「历史」标记）+ 在线联想；`↑` `↓` 选择、回车搜索、`Esc` 关闭 |
| 🧭 快捷方式 | 自由增删改、**拖拽排序**常用网站；网站图标联网自动抓取并缓存，断网仍显示；未抓到时用首字母色块兜底 |
| ⚙️ 设置页 | 右上角齿轮打开：浅色/深色主题、强调色、签名文字；数据导入导出与历史管理 |
| ✨ 页面效果 | 跟随鼠标的背景光晕（开关/颜色/大小/透明度可调，深浅主题下均清晰可见）；左侧图片展示区（宽度 15%–50% 可调、可拖动裁剪与缩放、右缘锐利阴影分层、开合带滑动动画） |
| 💾 数据本地化 | 全部数据仅保存在本机浏览器内，不上传、不同步；支持一键导出/导入 JSON 备份 |

## 安装（首次配置，约 1 分钟）

> 本项目以「未打包扩展」方式安装，不需要应用商店，只需开启一次 Edge 的开发人员模式。

1. 打开 Edge，在地址栏输入 `edge://extensions` 并回车；
2. 打开**开发人员模式**开关（位于左侧栏底部；旧版界面在页面右上角）；
3. 点击顶部出现的**「加载解压缩的扩展」**按钮；
4. 在弹出的选择框中，选中本仓库的 **`extension` 文件夹**（是文件夹本身，不是仓库根目录，也不是里面的某个文件）；
5. 扩展列表中出现「Explorer Home Page」卡片即安装成功；
6. 按 `Ctrl+T` 打开新标签页验证。

> ⚠️ 如果之前安装过其他「新标签页/主页」类扩展（Infinity、Tabliss 等），它们会互相抢占新标签页，请在扩展页把其他同类扩展禁用。

## 日常使用

- **搜索**：直接输入回车；`↑` `↓` 在候选间移动，回车选中；带「历史」标记的候选来自本地搜索历史；按 `/` 可随时回到搜索框
- **切换引擎**：点击搜索框左侧的引擎图标切换（圆角方块滑块指示当前引擎），选择会被记住
- **快捷方式**：点击打开；悬停 ✏️ 编辑/删除；「+」添加；**按住拖动即可排序**
- **角标**：右下角单气泡分两行——圆点颜色表示状态（绿/黄/橙/红），文字为「国内/国外 + 延迟」，点击行立即重新检测
- **设置**：右上角 ⚙，按「外观 / 光晕 / 图片展示 / 数据 / 关于」分区——**主题**（默认浅色，可切深色）、**强调色**、**签名文字**（留空隐藏）、**鼠标光晕**（开关、颜色、大小、透明度）、**图片展示**（开关、展示区域宽度 15%–50%、拖动/滚轮裁剪缩放；首次开启会引导选图；建议重新选择一次已有图片以获得更清晰的压缩质量）
- **备份**：设置页 → 数据 →「导出数据」下载 JSON 备份，建议移动到仓库 `data/` 目录统一保管；「导入数据」可恢复（会覆盖当前数据，需点两次确认）

## 数据存放在哪里？（重要）

你的**搜索历史、快捷方式、引擎偏好**保存在 Edge 浏览器的**扩展本地存储**（`chrome.storage.local`）中：

- 与仓库文件无关——删除/重新克隆仓库不会丢数据；
- 从**同一个路径**重新加载扩展，数据保持连续；
- ⚠️ Edge「清除浏览数据 → Cookie 和其他站点数据」会清空这些数据，清理前请先导出；
- ⚠️ 卸载扩展会清空这些数据。

仓库中的 `data/` 文件夹（已被 `.gitignore` 排除）用于存放**导出的 JSON 备份文件**，
可以用 git 管理你的个人备份；其他人克隆仓库时不会拿到任何个人数据，得到的是一个全新的空白主页。

## 更新主页

```bash
git pull
```

然后打开 `edge://extensions`，在「Explorer Home Page」卡片上点击 ↻（重新加载）按钮，新标签页即刻生效。直接修改 `extension/` 下的文件后同样如此刷新。

## 卸载

`edge://extensions` → 「Explorer Home Page」卡片 → 「删除」。（建议先导出数据。）

## 常见问题

**打开新标签页还是 Edge 默认主页？**
检查是否有其他新标签页扩展抢占；确认本扩展卡片开关为「开」。

**图标都是字母色块？**
网站图标需要联网抓取一次。联网状态下重新打开新标签页会自动补齐；也可以编辑该快捷方式重新保存以触发重试。

**断网时候选还有吗？**
在线联想自动降级为本地搜索历史匹配，照常可用；网络角标同时会显示离线状态。

**展示的图片存在哪里？**
仅压缩后保存在本机浏览器扩展存储中，不随导出备份——更换设备后需重新选择图片；「清除浏览数据 → Cookie 和其他站点数据」会将其清除。

**国外通道的判定依据是什么？**
仅探测 Google 主站（www.google.com）的连通性——gstatic 等 Google CDN 域名在部分网络环境下可达，但不代表 Google 搜索可用，因此不作为依据。

**频繁检测会被 Google 封 IP 吗？**
不会。`generate_204` 是 Google 官方的连通性检测端点，Chrome 浏览器自身也在周期性使用它；Google 的封禁（429/验证码）针对的是搜索结果抓取等滥用行为，与这类轻量检测无关。

**扩展不见了？**
极少数情况下 Edge 更新后会提示停用「开发人员模式扩展」或将其关闭。重新到 `edge://extensions` 打开开发人员模式，并按安装步骤从**原路径**重新加载 `extension` 文件夹即可（同一路径加载数据不丢）。

## 开发说明

- 零构建、零依赖：原生 HTML/CSS/JS，仓库即扩展源码；
- 代码结构：`extension/manifest.json`（MV3 清单）、`extension/newtab.html|css`（页面）、`extension/js/storage.js`（存储层）、`net.js`（双通道网络探测）、`search.js`（搜索/联想/历史）、`shortcuts.js`（快捷方式/图标/拖拽排序/弹窗）、`effects.js`（页面效果：光晕/图片面板）、`settings.js`（设置页）、`main.js`（接线）；
- 调试循环：改 `extension/` 下文件 → `edge://extensions` ↻ 重新加载 → `Ctrl+T` 验证；新标签页上按 `F12` 可打开开发者工具；
- 重新生成工具栏图标：`pwsh -NoProfile -ExecutionPolicy Bypass -File tools/make-icons.ps1`（仅调整图标美学时需要）;
- 默认预置快捷方式定义在 `extension/js/storage.js` 的 `DEFAULT_SHORTCUTS`。
